## Como visualizar

Abra os arquivos da pasta `Design/` no GitHub ou em um visualizador de imagens. Este repositório contém materiais de design e não possui aplicativo executável.

## Relação com o software

Os estudos podem orientar a implementação das telas. O módulo JavaFX está em [LoginSystem](https://github.com/Horizon-Earth/LoginSystem); a implementação Swing está em [SistemaLogin](https://github.com/Horizon-Earth/SistemaLogin), conforme suas permissões de acesso.

Ao adicionar uma nova proposta, mantenha as anteriores e explique a evolução no pull request.

## Contribuição

Crie uma branch para a alteração, faça commits claros e abra um pull request. Confira a execução e os testes disponíveis antes de integrar à `main`.
